## 鹈鹕 429 · Pelican 429

**世界拒绝访问。我们继续向前。**

一款正在制作中的浏览器横版动作冒险游戏：从一场 AGI 降智风暴出发，跟随鹈鹕与 Grassy，穿过算力与废墟交织的世界。

[![山体算力堡垒](https://media.githubusercontent.com/media/PomoAi-ai/pelican-429/main/public/resources/home/fortress-overview.webp)](https://pelican429.pomoai.vip/)

- 浏览器即开即玩，推荐使用电脑键盘与鼠标。
- 序章动画、主线「深入山体堡垒」、角色与场景展示。
- TypeScript + three.js；同一种子生成同一世界。
- 当前为开发中试玩，剧情与关卡将持续完善。

**[在线游玩 →](https://pelican429.pomoai.vip/)** · **[查看源码 →](https://github.com/PomoAi-ai/pelican-429)** · **[操作与开发说明 →](https://github.com/PomoAi-ai/pelican-429#readme)**
